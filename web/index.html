Descarga y revisa

Descarga el ZIP, abre el lector o entrega la carpeta para IA junto con las imágenes y el informe.

Lo que significa «completo»

Tener todas las preguntas no significa que la fuente incluya todas las explicaciones. El informe separa cobertura, revisión de imágenes y datos que faltan. Una transcripción automática siempre se marca como pendiente de revisión.

Si el sitio pide verificar el acceso

El motor puede esperar a que carguen las preguntas, pero una verificación que no se complete dejará un resultado parcial. Ese estado aparecerá en la ejecución y en el informe.

Conexión con tu repositorio

El frontend se publica en GitHub Pages. El trabajo se ejecuta en el repositorio que conectes. Puede ser otro repositorio privado para conservar allí los bancos de preguntas. El token de conexión no se incluye en el código ni se guarda al cerrar la pestaña.
