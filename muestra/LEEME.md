# Archivo de estudio

Abre preguntas.html para leer o imprimir; busca con Ctrl+F. El lector funciona sin JavaScript. Las capturas HTML originales se conservan dentro de archivos JSON como datos. Para una IA usa para_ia/LEEME_IA.md y entrega también las imágenes. Consulta informe_validacion.json para los pendientes. integridad_sha256.json verifica conservación, no certifica ausencia de malware ni exactitud académica.
