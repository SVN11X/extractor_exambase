GitHub Pages: publicar y reutilizar

Lee PUBLICAR_GITHUB_PAGES.md para publicar la interfaz, conectar el repositorio y descargar paquetes para estudiar o usar con una IA. Puedes guardar cada ejecución en el repositorio.

Este paquete está preparado para publicar; todavía no está conectado a tu cuenta.

En tu navegador habitual

Si ya usabas la extensión: cierra el panel, reemplaza los archivos dentro de la misma carpeta extension_navegador y pulsa Recargar en edge://extensions. Conserva la ruta y la extensión instalada para mantener tus preguntas.

  1. Abre el recopilador desde el icono de extensiones.
  2. Elige Proveedor → Ver exámenes o pega una URL de examen.
  3. Pulsa Seleccionar examen → Iniciar / reanudar.

Si es la primera instalación: edge://extensions → Modo de desarrollador → Cargar descomprimida → carpeta extension_navegador.

En GitHub Actions

El paquete incluye el workflow para elegir un examen de ejemplo o pegar una URL, ejecutarlo en un servidor y descargar su resultado como artefacto.

Sube el contenido de extractor_exambase a la raíz de un repositorio, incluyendo .github. Lee GITHUB_ACTIONS.md para los pasos.

El servidor no tiene tu sesión de Edge. Si la web exige una verificación que no termina, el flujo guardará un resultado parcial y se detendrá. No se ha ejecutado todavía en tu cuenta de GitHub.
