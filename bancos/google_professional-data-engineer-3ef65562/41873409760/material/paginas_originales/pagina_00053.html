Question 261

Single Answer

Topic 1

You want to migrate your existing Teradata data warehouse to BigQuery. You want to move the historical data to BigQuery by using the most efficient method that requires the least amount of programming, but local storage space on your existing data warehouse is limited. What should you do?
  • A
    Use BigQuery Data Transfer Service by using the Java Database Connectivity (JDBC) driver with FastExport connection.
    Correct
  • B
    Create a Teradata Parallel Transporter (TPT) export script to export the historical data, and import to BigQuery by using the bq command-line tool.
  • C
    Use BigQuery Data Transfer Service with the Teradata Parallel Transporter (TPT) tbuild utility.
  • D
    Create a script to export the historical data, and upload in batches to Cloud Storage. Set up a BigQuery Data Transfer Service instance from Cloud Storage to BigQuery.
Explanation
The question specifies that local storage space on the existing Teradata system is limited. FastExport, when used with the JDBC driver, supports direct streaming of data to BigQuery via the BigQuery Data Transfer Service, thereby eliminating the need to write intermediate data files to local disk.
In contrast, TPT (Teradata Parallel Transporter) typically requires generating local files (even if optimized with tbuild) or relies on local buffer space, making it less suitable when local storage is a strict constraint. Google's documentation for Teradata migration explicitly recommends the JDBC/FastExport method when local storage constraints prevent the use of TPT or file-based exports. This approach also satisfies the requirement for minimal programming by leveraging the managed Data Transfer Service.

Question 262

Single Answer

Topic 1

You are on the data governance team and are implementing security requirements. You need to encrypt all your data in BigQuery by using an encryption key managed by your team. You must implement a mechanism to generate and store encryption material only on your on-premises hardware security module (HSM). You want to rely on Google managed solutions. What should you do?
  • A
    Create the encryption key in the on-premises HSM, and import it into a Cloud Key Management Service (Cloud KMS) key. Associate the created Cloud KMS key while creating the BigQuery resources.
  • B
    Create the encryption key in the on-premises HSM and link it to a Cloud External Key Manager (Cloud EKM) key. Associate the created Cloud KMS key while creating the BigQuery resources.
    Correct
  • C
    Create the encryption key in the on-premises HSM, and import it into Cloud Key Management Service (Cloud HSM) key. Associate the created Cloud HSM key while creating the BigQuery resources.
  • D
    Create the encryption key in the on-premises HSM. Create BigQuery resources and encrypt data while ingesting them into BigQuery.
Explanation
Cloud External Key Manager (Cloud EKM) is the specific Google Cloud solution designed to integrate BigQuery with external key management systems, such as an on-premises HSM.
This allows the encryption key material to remain exclusively within your on-premises hardware while BigQuery uses the associated Cloud KMS cryptographic key for encryption operations.
Options involving Cloud KMS import or Cloud HSM would store or replicate key material within Google's infrastructure, violating the requirement that material be stored only on-premises.

Question 263

Single Answer

Topic 1

You maintain ETL pipelines. You notice that a streaming pipeline running on Dataflow is taking a long time to process incoming data, which causes output delays. You also noticed that the pipeline graph was automatically optimized by Dataflow and merged into one step. You want to identify where the potential bottleneck is occurring. What should you do?
  • A
    Insert a Reshuffle operation after each processing step, and monitor the execution details in the Dataflow console.
    Correct
  • B
    Insert output sinks after each key processing step, and observe the writing throughput of each block.
  • C
    Log debug information in each ParDo function, and analyze the logs at execution time.
  • D
    Verify that the Dataflow service accounts have appropriate permissions to write the processed data to the output sinks.
Explanation
The Dataflow service automatically fuses multiple transforms into single steps to optimize performance, which can obscure individual step latencies. Inserting a Reshuffle operation breaks this fusion boundary, forcing the pipeline to execute distinct stages that can be individually monitored in the Dataflow console. This allows you to isolate and identify the specific transform causing the processing bottleneck.

Question 264

Single Answer

Topic 1

You are running your BigQuery project in the on-demand billing model and are executing a change data capture (CDC) process that ingests data. The CDC process loads 1 GB of data every 10 minutes into a temporary table, and then performs a merge into a 10 TB target table. This process is very scan intensive and you want to explore options to enable a predictable cost model. You need to create a BigQuery reservation based on utilization information gathered from BigQuery Monitoring and apply the reservation to the CDC process. What should you do?
  • A
    Create a BigQuery reservation for the dataset.
  • B
    Create a BigQuery reservation for the job.
  • C
    Create a BigQuery reservation for the service account running the job.
  • D
    Create a BigQuery reservation for the project.
    Correct
Explanation
BigQuery reservations are assigned to resources at the project, folder, or organization level in the resource hierarchy.
Slots cannot be directly assigned to datasets, service accounts, or individual jobs.
To apply capacity controls to the CDC process, you must create and assign a reservation to the specific project running those jobs.

Question 265

Single Answer

Topic 1

You are designing a fault-tolerant architecture to store data in a regional BigQuery dataset. You need to ensure that your application is able to recover from a corruption event in your tables that occurred within the past seven days. You want to adopt managed services with the lowest RPO and most cost-effective solution. What should you do?
  • A
    Access historical data by using time travel in BigQuery.
    Correct
  • B
    Export the data from BigQuery into a new table that excludes the corrupted data
  • C
    Create a BigQuery table snapshot on a daily basis.
  • D
    Migrate your data to multi-region BigQuery buckets.
Explanation
BigQuery Time Travel provides the lowest RPO (near-zero data loss) by allowing access to table states up to seven days in the past, satisfying the recovery window requirement.

It is the most cost-effective solution because it is a built-in feature with no additional storage costs for the historical data retained within the default window, unlike snapshots which incur incremental storage fees.
