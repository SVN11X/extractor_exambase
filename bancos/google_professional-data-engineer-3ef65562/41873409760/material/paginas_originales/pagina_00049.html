Question 241

Single Answer

Topic 1

You are designing the architecture of your application to store data in Cloud Storage. Your application consists of pipelines that read data from a Cloud Storage bucket that contains raw data, and write the data to a second bucket after processing. You want to design an architecture with Cloud Storage resources that are capable of being resilient if a Google Cloud regional failure occurs. You want to minimize the recovery point objective (RPO) if a failure occurs, with no impact on applications that use the stored data. What should you do?
  • A
    Adopt multi-regional Cloud Storage buckets in your architecture.
  • B
    Adopt two regional Cloud Storage buckets, and update your application to write the output on both buckets.
  • C
    Adopt a dual-region Cloud Storage bucket, and enable turbo replication in your architecture.
    Correct
  • D
    Adopt two regional Cloud Storage buckets, and create a daily task to copy from one bucket to the other.
Explanation
Dual-region buckets replicate data across two specific geographic regions, providing resilience against regional failures. Enabling Turbo Replication significantly reduces the Recovery Point Objective (RPO) to a target of 15 minutes for 100% of objects, compared to up to 12 hours for default replication. This configuration meets the requirement to minimize RPO without impacting application logic or requiring manual intervention.

Question 242

Single Answer

Topic 1

You have designed an Apache Beam processing pipeline that reads from a Pub/Sub topic. The topic has a message retention duration of one day, and writes to a Cloud Storage bucket. You need to select a bucket location and processing strategy to prevent data loss in case of a regional outage with an RPO of 15 minutes. What should you do?
  • A
    1. Use a dual-region Cloud Storage bucket.
    2. Monitor Dataflow metrics with Cloud Monitoring to determine when an outage occurs.
    3. Seek the subscription back in time by 15 minutes to recover the acknowledged messages.
    4. Start the Dataflow job in a secondary region.
  • B
    1. Use a multi-regional Cloud Storage bucket.
    2. Monitor Dataflow metrics with Cloud Monitoring to determine when an outage occurs.
    3. Seek the subscription back in time by 60 minutes to recover the acknowledged messages.
    4. Start the Dataflow job in a secondary region.
  • C
    1. Use a regional Cloud Storage bucket.
    2. Monitor Dataflow metrics with Cloud Monitoring to determine when an outage occurs.
    3. Seek the subscription back in time by one day to recover the acknowledged messages.
    4. Start the Dataflow job in a secondary region and write in a bucket in the same region.
  • D
    1. Use a dual-region Cloud Storage bucket with turbo replication enabled.
    2. Monitor Dataflow metrics with Cloud Monitoring to determine when an outage occurs.
    3. Seek the subscription back in time by 60 minutes to recover the acknowledged messages.
    4. Start the Dataflow job in a secondary region.
    Correct
Explanation
A dual-region Cloud Storage bucket with Turbo Replication ensures that objects are replicated to both regions within the specified Recovery Point Objective (RPO) of 15 minutes, meeting the data loss prevention requirement.
While a standard dual-region bucket may take up to an hour for replication, enabling Turbo Replication guarantees synchronization within the 15-minute window required by the scenario.

Question 244

Single Answer

Topic 1

Different teams in your organization store customer and performance data in BigQuery. Each team needs to keep full control of their collected data, be able to query data within their projects, and be able to exchange their data with other teams. You need to implement an organization-wide solution, while minimizing operational tasks and costs. What should you do?
  • A
    Ask each team to create authorized views of their data. Grant the biquery.jobUser role to each team.
  • B
    Create a BigQuery scheduled query to replicate all customer data into team projects.
  • C
    Ask each team to publish their data in Analytics Hub. Direct the other teams to subscribe to them.
    Correct
  • D
    Enable each team to create materialized views of the data they need to access in their projects.
Explanation
BigQuery Analytics Hub is the designated solution for controlled data sharing across projects while maintaining producer ownership. It allows teams to publish datasets as data products, enabling consumers to subscribe and query without duplicating data or managing complex IAM permissions. This approach minimizes operational overhead and storage costs by eliminating the need for manual replication or ETL pipelines.

Question 245

Single Answer

Topic 1

You are developing a model to identify the factors that lead to sales conversions for your customers. You have completed processing your data. You want to continue through the model development lifecycle. What should you do next?
  • A
    Use your model to run predictions on fresh customer input data.
  • B
    Monitor your model performance, and make any adjustments needed.
  • C
    Delineate what data will be used for testing and what will be used for training the model.
    Correct
  • D
    Test and evaluate your model on your curated data to determine how well the model performs.
Explanation
In the machine learning lifecycle, data must be split into training and testing sets before model training begins to ensure valid performance evaluation. Since data processing is complete but training has not started, delineating these datasets (Option C) is the necessary prerequisite step. Options A, B, and D involve prediction, monitoring, or evaluation, which require a trained model that does not yet exist.
