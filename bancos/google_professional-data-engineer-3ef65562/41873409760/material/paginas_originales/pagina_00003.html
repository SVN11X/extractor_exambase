Question 11

Single Answer

Topic 1

You are designing a basket abandonment system for an ecommerce company. The system will send a message to a user based on these rules:
✑ No interaction by the user on the site for 1 hour
Has added more than $30 worth of products to the basket

✑ Has not completed a transaction
You use Google Cloud Dataflow to process the data and decide if a message should be sent. How should you design the pipeline?
  • A
    Use a fixed-time window with a duration of 60 minutes.
  • B
    Use a sliding time window with a duration of 60 minutes.
  • C
    Use a session window with a gap time duration of 60 minutes.
    Correct
  • D
    Use a global window with a time based trigger with a delay of 60 minutes.
Explanation
Session windows are the correct choice because they dynamically group events into sessions based on periods of activity and inactivity. By setting a gap duration of 60 minutes, the system effectively identifies users who have stopped interacting for one hour, allowing you to evaluate their basket state at that precise moment. Fixed or sliding windows would impose rigid time boundaries unrelated to user behavior, while global windows lack the built-in session isolation needed here.

Question 12

Multiple Answers

Topic 1

Your company handles data processing for a number of different clients. Each client prefers to use their own suite of analytics tools, with some allowing direct query access via Google BigQuery. You need to secure the data so that clients cannot see each other's data. You want to ensure appropriate access to the data.
Which three steps should you take? (Choose three.)
  • A
    Load data into different partitions.
  • B
    Load data into a different dataset for each client.
    Correct
  • C
    Put each client's BigQuery dataset into a different table.
  • D
    Restrict a client's dataset to approved users.
    Correct
  • E
    Only allow a service account to access the datasets.
  • F
    Use the appropriate identity and access management (IAM) roles for each client's users.
    Correct
Explanation
To ensure client data isolation in BigQuery, you should load each client's data into a separate dataset (B), as datasets are the primary units for access control. You must then restrict access to these datasets by assigning only approved users or groups (D). Finally, applying specific IAM roles (F) allows you to define granular permissions for those users, ensuring they can only access their own client's data and not others.

Question 13

Single Answer

Topic 1

You want to process payment transactions in a point-of-sale application that will run on Google Cloud Platform. Your user base could grow exponentially, but you do not want to manage infrastructure scaling.
Which Google database service should you use?
  • A
    Cloud SQL
  • B
    BigQuery
  • C
    Cloud Bigtable
  • D
    Cloud Datastore
    Correct
Explanation
The requirement to avoid managing infrastructure scaling points to a fully managed, serverless database that scales automatically.
Cloud SQL requires manual configuration for CPU and memory scaling (vertical scaling), whereas Cloud Datastore (Firestore in Datastore mode) handles scaling transparently.
Additionally, Google explicitly lists financial transactions as a use case for Cloud Datastore due to its ACID transaction support, making it the superior choice for this specific workload.

Question 14

Multiple Answers

Topic 1

You want to use a database of information about tissue samples to classify future tissue samples as either normal or mutated. You are evaluating an unsupervised anomaly detection method for classifying the tissue samples. Which two characteristic support this method? (Choose two.)
  • A
    There are very few occurrences of mutations relative to normal samples.
    Correct
  • B
    There are roughly equal occurrences of both normal and mutated samples in the database.
  • C
    You expect future mutations to have different features from the mutated samples in the database.
    Correct
  • D
    You expect future mutations to have similar features to the mutated samples in the database.
  • E
    You already have labels for which samples are mutated and which are normal in the database.
Explanation
Unsupervised anomaly detection relies on the assumption that anomalies are rare events, making option A correct as it reflects the class imbalance typical in such datasets.
Option C is also correct because unsupervised methods model the distribution of normal data; they detect any significant deviation from this norm, regardless of whether future mutations resemble past specific mutation patterns or exhibit novel features.

Question 15

Single Answer

Topic 1

You need to store and analyze social media postings in Google BigQuery at a rate of 10,000 messages per minute in near real-time. Initially, design the application to use streaming inserts for individual postings. Your application also performs data aggregations right after the streaming inserts. You discover that the queries after streaming inserts do not exhibit strong consistency, and reports from the queries might miss in-flight data. How can you adjust your application design?
  • A
    Re-write the application to load accumulated data every 2 minutes.
  • B
    Convert the streaming insert code to batch load for individual messages.
  • C
    Load the original message to Google Cloud SQL, and export the table every hour to BigQuery via streaming inserts.
  • D
    Estimate the average latency for data availability after streaming inserts, and always run queries after waiting twice as long.
    Correct
Explanation
BigQuery streaming inserts provide eventual consistency, meaning data may not be immediately available for querying due to internal buffering.
Option D is the correct answer in the context of this exam question because it suggests adjusting the application logic to wait for a period longer than the estimated latency (e.g., twice the average) before running queries, ensuring the data has been flushed and is visible.
This approach acknowledges the inherent delay of streaming inserts without switching to batch loads or external databases, which would violate the near real-time requirement.
