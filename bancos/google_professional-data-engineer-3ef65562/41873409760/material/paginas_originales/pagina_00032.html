Question 156

Single Answer

Topic 1

You are planning to migrate your current on-premises Apache Hadoop deployment to the cloud. You need to ensure that the deployment is as fault-tolerant and cost-effective as possible for long-running batch jobs. You want to use a managed service. What should you do?
  • A
    Deploy a Dataproc cluster. Use a standard persistent disk and 50% preemptible workers. Store data in Cloud Storage, and change references in scripts from hdfs:// to gs://
    Correct
  • B
    Deploy a Dataproc cluster. Use an SSD persistent disk and 50% preemptible workers. Store data in Cloud Storage, and change references in scripts from hdfs:// to gs://
  • C
    Install Hadoop and Spark on a 10-node Compute Engine instance group with standard instances. Install the Cloud Storage connector, and store the data in Cloud Storage. Change references in scripts from hdfs:// to gs://
  • D
    Install Hadoop and Spark on a 10-node Compute Engine instance group with preemptible instances. Store data in HDFS. Change references in scripts from hdfs:// to gs://
Explanation
Option A is correct because Cloud Dataproc is the recommended managed service for migrating Hadoop deployments, ensuring fault tolerance and simplified operations. Using standard persistent disks (HDD) instead of SSDs optimizes cost-effectiveness for long-running batch jobs that do not require high IOPS or low latency. Storing data in Cloud Storage and using preemptible workers further reduces costs while maintaining durability.

Question 157

Single Answer

Topic 1

Your team is working on a binary classification problem. You have trained a support vector machine (SVM) classifier with default parameters, and received an area under the Curve (AUC) of 0.87 on the validation set. You want to increase the AUC of the model. What should you do?
  • A
    Perform hyperparameter tuning
    Correct
  • B
    Train a classifier with deep neural networks, because neural networks would always beat SVMs
  • C
    Deploy the model and measure the real-world AUC; it's always higher because of generalization
  • D
    Scale predictions you get out of the model (tune a scaling factor as a hyperparameter) in order to get the highest AUC
Explanation
Hyperparameter tuning optimizes the SVM's internal parameters (such as C and gamma) to better fit the data distribution, which is the standard method for improving model performance beyond default settings.
Option D is incorrect because scaling predictions alters the confidence scores but does not change the rank order used to calculate AUC, making it mathematically ineffective.

Question 158

Single Answer

Topic 1

You need to deploy additional dependencies to all nodes of a Cloud Dataproc cluster at startup using an existing initialization action. Company security policies require that Cloud Dataproc nodes do not have access to the Internet so public initialization actions cannot fetch resources. What should you do?
  • A
    Deploy the Cloud SQL Proxy on the Cloud Dataproc master
  • B
    Use an SSH tunnel to give the Cloud Dataproc cluster access to the Internet
  • C
    Copy all dependencies to a Cloud Storage bucket within your VPC security perimeter
    Correct
  • D
    Use Resource Manager to add the service account used by the Cloud Dataproc cluster to the Network User role
Explanation
Cloud Dataproc initialization actions can retrieve dependencies from Cloud Storage buckets without requiring public Internet access.
By placing the dependencies in a bucket within your VPC security perimeter and enabling Private Google Access, cluster nodes with internal-only IP addresses can download the files privately.
This approach adheres to the security policy prohibiting Internet connectivity while satisfying the requirement to deploy dependencies at startup.

Question 159

Single Answer

Topic 1

You need to choose a database for a new project that has the following requirements:
✑ Fully managed
✑ Able to automatically scale up
✑ Transactionally consistent
✑ Able to scale up to 6 TB
✑ Able to be queried using SQL
Which database do you choose?
  • A
    Cloud SQL
  • B
    Cloud Bigtable
  • C
    Cloud Spanner
    Correct
  • D
    Cloud Datastore
Explanation
Cloud Spanner is the correct choice because it is the only fully managed relational database on GCP that supports automatic, seamless horizontal scaling of compute capacity (nodes) alongside storage.
While Cloud SQL automatically scales storage, it requires manual intervention or custom automation to scale CPU and memory resources, failing the 'automatically scale up' requirement for compute.
Spanner provides full ACID transactional consistency and standard SQL support while handling large datasets up to 6 TB without requiring schema changes or sharding logic.

Question 160

Single Answer

Topic 1

You work for a mid-sized enterprise that needs to move its operational system transaction data from an on-premises database to GCP. The database is about 20
TB in size. Which database should you choose?
  • A
    Cloud SQL
    Correct
  • B
    Cloud Bigtable
  • C
    Cloud Spanner
  • D
    Cloud Datastore
Explanation
The correct answer is Cloud SQL because it is the managed relational database service designed for migrating standard on-premises operational databases (such as MySQL, PostgreSQL, or SQL Server).
Although older exam materials suggested a lower storage limit, Cloud SQL supports up to 64 TB of storage, which accommodates the required 20 TB dataset.
Cloud Spanner is typically reserved for scenarios requiring global horizontal scalability and strict consistency across regions, while Bigtable is a NoSQL solution unsuitable for direct relational database migration without significant refactoring.
