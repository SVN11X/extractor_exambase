Question 66

Single Answer

Topic 1

Your company has an existing GCP organization with hundreds of projects and a billing account. Your company recently acquired another company that also has hundreds of projects and its own billing account. You would like to consolidate all GCP costs of both GCP organizations onto a single invoice. You would like to consolidate all costs as of tomorrow. What should you do?
  • A
    Link the acquired company's projects to your company's billing account.
    Correct
  • B
    Configure the acquired company's billing account and your company's billing account to export the billing data into the same BigQuery dataset.
  • C
    Migrate the acquired company's projects into your company's GCP organization. Link the migrated projects to your company's billing account.
  • D
    Create a new GCP organization and a new billing account. Migrate the acquired company's projects and your company's projects into the new GCP organization and link the projects to the new billing account.
Explanation
The requirement is to consolidate costs onto a single invoice immediately ('as of tomorrow'). BigQuery exports (Option B) provide data for analysis but do not change the billing entity or generate a unified invoice from Google. Migrating projects between organizations (Options C and D) is a complex process requiring GCP Support involvement and cannot be completed overnight. Linking the acquired company's projects directly to your existing billing account (Option A) is technically supported across different organizations and immediately consolidates charges under one payment source.

Question 67

Single Answer

Topic 1

You built an application on Google Cloud that uses Cloud Spanner. Your support team needs to monitor the environment but should not have access to table data.
You need a streamlined solution to grant the correct permissions to your support team, and you want to follow Google-recommended practices. What should you do?
  • A
    Add the support team group to the roles/monitoring.viewer role
    Correct
  • B
    Add the support team group to the roles/spanner.databaseUser role.
  • C
    Add the support team group to the roles/spanner.databaseReader role.
  • D
    Add the support team group to the roles/stackdriver.accounts.viewer role.
Explanation
The requirement is to allow monitoring without accessing table data. The `roles/monitoring.viewer` role grants read-only access to Cloud Monitoring data, enabling the support team to view metrics and logs relevant to Cloud Spanner health and performance.

In contrast, `roles/spanner.databaseUser` and `roles/spanner.databaseReader` grant permissions to query or modify table data, violating the restriction. `roles/stackdriver.accounts.viewer` only allows viewing account structure metadata, not operational monitoring data.

Question 68

Single Answer

Topic 1

For analysis purposes, you need to send all the logs from all of your Compute Engine instances to a BigQuery dataset called platform-logs. You have already installed the Cloud Logging agent on all the instances. You want to minimize cost. What should you do?
  • A
    1. Give the BigQuery Data Editor role on the platform-logs dataset to the service accounts used by your instances. 2. Update your instances' metadata to add the following value: logs-destination: bq://platform-logs.
  • B
    1. In Cloud Logging, create a logs export with a Cloud Pub/Sub topic called logs as a sink. 2. Create a Cloud Function that is triggered by messages in the logs topic. 3. Configure that Cloud Function to drop logs that are not from Compute Engine and to insert Compute Engine logs in the platform-logs dataset.
  • C
    1. In Cloud Logging, create a filter to view only Compute Engine logs. 2. Click Create Export. 3. Choose BigQuery as Sink Service, and the platform-logs dataset as Sink Destination.
    Correct
  • D
    1. Create a Cloud Function that has the BigQuery User role on the platform-logs dataset. 2. Configure this Cloud Function to create a BigQuery Job that executes this query: INSERT INTO dataset.platform-logs (timestamp, log) SELECT timestamp, log FROM compute.logs WHERE timestamp > DATE_SUB(CURRENT_DATE(), INTERVAL 1 DAY) 3. Use Cloud Scheduler to trigger this Cloud Function once a day.
Explanation
Option C is the correct approach because it uses Cloud Logging's native export feature with a filter to selectively send only Compute Engine logs to BigQuery.
This method minimizes cost by reducing data volume and storage compared to exporting all logs or using additional services like Pub/Sub and Cloud Functions.
The other options introduce unnecessary complexity, higher latency, or incur significant compute costs through custom code execution.

Question 69

Single Answer

Topic 1

You are using Deployment Manager to create a Google Kubernetes Engine cluster. Using the same Deployment Manager deployment, you also want to create a
DaemonSet in the kube-system namespace of the cluster. You want a solution that uses the fewest possible services. What should you do?
  • A
    Add the cluster's API as a new Type Provider in Deployment Manager, and use the new type to create the DaemonSet.
    Correct
  • B
    Use the Deployment Manager Runtime Configurator to create a new Config resource that contains the DaemonSet definition.
  • C
    With Deployment Manager, create a Compute Engine instance with a startup script that uses kubectl to create the DaemonSet.
  • D
    In the cluster's definition in Deployment Manager, add a metadata that has kube-system as key and the DaemonSet manifest as value.
Explanation
Adding the GKE cluster API as a Type Provider in Deployment Manager allows you to manage Kubernetes resources like DaemonSets directly within your Deployment Manager configuration.
This approach uses the fewest services because it relies solely on Deployment Manager and GKE, avoiding the need for additional Compute Engine instances or startup scripts.
Other options introduce extra infrastructure overhead or are technically invalid for direct resource creation.

Question 70

Single Answer

Topic 1

You are building an application that will run in your data center. The application will use Google Cloud Platform (GCP) services like AutoML. You created a service account that has appropriate access to AutoML. You need to enable authentication to the APIs from your on-premises environment. What should you do?
  • A
    Use service account credentials in your on-premises application.
  • B
    Use gcloud to create a key file for the service account that has appropriate permissions.
    Correct
  • C
    Set up direct interconnect between your data center and Google Cloud Platform to enable authentication for your on-premises applications.
  • D
    Go to the IAM & admin console, grant a user account permissions similar to the service account permissions, and use this user account for authentication from your data center.
Explanation
Service accounts running outside of Google Cloud (on-premises) require a service account key file to authenticate because they cannot automatically retrieve short-lived tokens.
Generating a JSON key file using `gcloud` or the console provides the necessary private key for the on-premises application to sign requests and prove its identity to GCP APIs.
