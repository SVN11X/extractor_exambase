Question 31

Single Answer

Topic 1

You want to send and consume Cloud Pub/Sub messages from your App Engine application. The Cloud Pub/Sub API is currently disabled. You will use a service account to authenticate your application to the API. You want to make sure your application can use Cloud Pub/Sub. What should you do?
  • A
    Enable the Cloud Pub/Sub API in the API Library on the GCP Console.
    Correct
  • B
    Rely on the automatic enablement of the Cloud Pub/Sub API when the Service Account accesses it.
  • C
    Use Deployment Manager to deploy your application. Rely on the automatic enablement of all APIs used by the application being deployed.
  • D
    Grant the App Engine Default service account the role of Cloud Pub/Sub Admin. Have your application enable the API on the first connection to Cloud Pub/ Sub.
Explanation
In Google Cloud Platform, most APIs are disabled by default to minimize costs and security risks. To use Cloud Pub/Sub, the API must be explicitly enabled in the project via the API Library or CLI before any application code can interact with it. Automatic enablement does not occur upon first access or through standard service account authentication.

Question 32

Single Answer

Topic 1

You need to monitor resources that are distributed over different projects in Google Cloud Platform. You want to consolidate reporting under the same Stackdriver
Monitoring dashboard. What should you do?
  • A
    Use Shared VPC to connect all projects, and link Stackdriver to one of the projects.
  • B
    For each project, create a Stackdriver account. In each project, create a service account for that project and grant it the role of Stackdriver Account Editor in all other projects.
  • C
    Configure a single Stackdriver account, and link all projects to the same account.
    Correct
  • D
    Configure a single Stackdriver account for one of the projects. In Stackdriver, create a Group and add the other project names as criteria for that Group.
Explanation
To consolidate monitoring data from multiple projects into a single dashboard, you must use a Cloud Monitoring workspace that can link to multiple GCP projects.
Option C correctly describes configuring a single Stackdriver (Cloud Monitoring) account and linking all relevant projects to it via the workspace settings.
Option D is incorrect because Groups are designed for organizing resources like VMs or load balancers, not for aggregating entire projects into a unified monitoring view.

Question 33

Single Answer

Topic 1

You are deploying an application to a Compute Engine VM in a managed instance group. The application must be running at all times, but only a single instance of the VM should run per GCP project. How should you configure the instance group?
  • A
    Set autoscaling to On, set the minimum number of instances to 1, and then set the maximum number of instances to 1.
    Correct
  • B
    Set autoscaling to Off, set the minimum number of instances to 1, and then set the maximum number of instances to 1.
  • C
    Set autoscaling to On, set the minimum number of instances to 1, and then set the maximum number of instances to 2.
  • D
    Set autoscaling to Off, set the minimum number of instances to 1, and then set the maximum number of instances to 2.
Explanation
To ensure exactly one instance runs at all times, autoscaling must be enabled so the manager actively maintains the target count against failures or deletions.
With autoscaling On and both min/max set to 1, the system guarantees a single running instance by automatically recreating it if it stops.
Setting autoscaling Off (Choice B) leaves the static instance vulnerable to staying down after a crash unless autohealing is explicitly configured separately.

Question 34

Topic 1

You want to verify the IAM users and roles assigned within a GCP project named my-project. What should you do?
  • A
    Run gcloud iam roles list. Review the output section.
  • B
    Run gcloud iam service-accounts list. Review the output section.
  • C
    Navigate to the project and then to the IAM section in the GCP Console. Review the members and roles.
    Correct
  • D
    Navigate to the project and then to the Roles section in the GCP Console. Review the roles and status.
Explanation
The IAM section in the GCP Console explicitly maps principals (users and roles) to their assigned permissions within a specific project.
Option A lists only available role definitions, Option B lists only service accounts, and Option D focuses on role definitions rather than assignments.

Question 35

Single Answer

Topic 1

You need to create a new billing account and then link it with an existing Google Cloud Platform project. What should you do?
  • A
    Verify that you are Project Billing Manager for the GCP project. Update the existing project to link it to the existing billing account.
  • B
    Verify that you are Project Billing Manager for the GCP project. Create a new billing account and link the new billing account to the existing project.
    Correct
  • C
    Verify that you are Billing Administrator for the billing account. Create a new project and link the new project to the existing billing account.
  • D
    Verify that you are Billing Administrator for the billing account. Update the existing project to link it to the existing billing account.
Explanation
The question requires creating a NEW billing account and linking it to an EXISTING project. Option B is the only choice that explicitly mentions creating a 'new billing account' and linking it to an 'existing project'. Although the permission model described in the options is technically imprecise (as Billing Account Administrators manage but do not typically create accounts, requiring a specific creator role or organization admin privileges), Option B is the best fit by process of elimination against options that reference non-existent resources or incorrect actions.
