Question 166

Single Answer

Topic 1

Your web application has been running successfully on Cloud Run for Anthos. You want to evaluate an updated version of the application with a specific percentage of your production users (canary deployment). What should you do?
  • A
    Create a new service with the new version of the application. Split traffic between this version and the version that is currently running.
  • B
    Create a new revision with the new version of the application. Split traffic between this version and the version that is currently running.
    Correct
  • C
    Create a new service with the new version of the application. Add an HTTP Load Balancer in front of both services.
  • D
    Create a new revision with the new version of the application. Add an HTTP Load Balancer in front of both revisions.
Explanation
In Cloud Run for Anthos (and standard Cloud Run), a deployment update is managed by creating a new revision within the existing service, not by creating a separate service.
Cloud Run provides built-in traffic splitting capabilities at the service level, allowing you to route a specific percentage of traffic between different revisions for canary testing.

Question 167

Single Answer

Topic 1

Your company developed a mobile game that is deployed on Google Cloud. Gamers are connecting to the game with their personal phones over the Internet. The game sends UDP packets to update the servers about the gamers' actions while they are playing in multiplayer mode. Your game backend can scale over multiple virtual machines (VMs), and you want to expose the VMs over a single IP address. What should you do?
  • A
    Configure an SSL Proxy load balancer in front of the application servers.
  • B
    Configure an Internal UDP load balancer in front of the application servers.
  • C
    Configure an External HTTP(s) load balancer in front of the application servers.
  • D
    Configure an External Network load balancer in front of the application servers.
    Correct
Explanation
The requirement to handle UDP traffic eliminates SSL Proxy (TCP-only) and HTTP(s) Load Balancers (HTTP/HTTPS only).
Between the remaining options, External Network Load Balancing is required because clients are connecting from the Internet, whereas Internal Load Balancing is restricted to VPC internal traffic.
External Network Load Balancer supports raw TCP/UDP forwarding and exposes a single external IP for backend VMs.

Question 168

Single Answer

Topic 1

You are working for a hospital that stores its medical images in an on-premises data room. The hospital wants to use Cloud Storage for archival storage of these images. The hospital wants an automated process to upload any new medical images to Cloud Storage. You need to design and implement a solution. What should you do?
  • A
    Create a Pub/Sub topic, and enable a Cloud Storage trigger for the Pub/Sub topic. Create an application that sends all medical images to the Pub/Sub topic.
  • B
    Deploy a Dataflow job from the batch template, "Datastore to Cloud Storage." Schedule the batch job on the desired interval.
  • C
    Create a script that uses the gsutil command line interface to synchronize the on-premises storage with Cloud Storage. Schedule the script as a cron job.
    Correct
  • D
    In the Cloud Console, go to Cloud Storage. Upload the relevant images to the appropriate bucket.
Explanation
Option C is correct because gsutil rsync provides a robust, automated way to synchronize on-premises directories with Cloud Storage buckets.
Scheduling the script via cron meets the requirement for an automated process without the complexity of Pub/Sub (which is not designed for large binary data transfer) or Dataflow (which is overkill for simple file synchronization).
Option A is technically flawed as Pub/Sub has message size limits unsuitable for medical images, and Option D requires manual intervention.

Question 169

Single Answer

Topic 1

Your auditor wants to view your organization's use of data in Google Cloud. The auditor is most interested in auditing who accessed data in Cloud Storage buckets. You need to help the auditor access the data they need. What should you do?
  • A
    Turn on Data Access Logs for the buckets they want to audit, and then build a query in the log viewer that filters on Cloud Storage.
    Correct
  • B
    Assign the appropriate permissions, and then create a Data Studio report on Admin Activity Audit Logs.
  • C
    Assign the appropriate permissions, and then use Cloud Monitoring to review metrics.
  • D
    Use the export logs API to provide the Admin Activity Audit Logs in the format they want.
Explanation
Data Access Audit Logs for Cloud Storage are not enabled by default because they generate a high volume of entries. To audit who accessed the data, you must first explicitly enable these logs on the relevant buckets and then query them using the Log Viewer.

Question 170

Single Answer

Topic 1

You received a JSON file that contained a private key of a Service Account in order to get access to several resources in a Google Cloud project. You downloaded and installed the Cloud SDK and want to use this private key for authentication and authorization when performing gcloud commands. What should you do?
  • A
    Use the command gcloud auth login and point it to the private key.
  • B
    Use the command gcloud auth activate-service-account and point it to the private key.
    Correct
  • C
    Place the private key file in the installation directory of the Cloud SDK and rename it to "credentials.json".
  • D
    Place the private key file in your home directory and rename it to "GOOGLE_APPLICATION_CREDENTIALS".
Explanation
The correct method to authenticate gcloud CLI with a service account key file is using `gcloud auth activate-service-account` with the `--key-file` flag. This command imports the credentials and sets the service account as the active identity in your Cloud SDK configuration.

Option A (`gcloud auth login`) is primarily for interactive user authentication, though newer versions support service accounts via specific flags not mentioned here. Option D refers to Application Default Credentials (ADC), which are used by applications running on GCP or locally with a specific environment variable, not for direct CLI activation via a key file path argument.
