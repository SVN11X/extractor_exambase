Question 141

Single Answer

Topic 1

You created several resources in multiple Google Cloud projects. All projects are linked to different billing accounts. To better estimate future charges, you want to have a single visual representation of all costs incurred. You want to include new cost data as soon as possible. What should you do?
  • A
    Configure Billing Data Export to BigQuery and visualize the data in Data Studio.
    Correct
  • B
    Visit the Cost Table page to get a CSV export and visualize it using Data Studio.
  • C
    Fill all resources in the Pricing Calculator to get an estimate of the monthly cost.
  • D
    Use the Reports view in the Cloud Billing Console to view the desired cost information.
Explanation
Option A is correct because exporting billing data to BigQuery allows for the aggregation of cost information across multiple projects and billing accounts into a single dataset. This granular data can then be visualized in Data Studio (Looker Studio) to create a unified, real-time cost dashboard, whereas the Cloud Billing Console reports are limited to individual billing accounts.

Question 142

Single Answer

Topic 1

Your company has workloads running on Compute Engine and on-premises. The Google Cloud Virtual Private Cloud (VPC) is connected to your WAN over a
Virtual Private Network (VPN). You need to deploy a new Compute Engine instance and ensure that no public Internet traffic can be routed to it. What should you do?
  • A
    Create the instance without a public IP address.
    Correct
  • B
    Create the instance with Private Google Access enabled.
  • C
    Create a deny-all egress firewall rule on the VPC network.
  • D
    Create a route on the VPC to route all traffic to the instance over the VPN tunnel.
Explanation
To prevent public Internet traffic from reaching a Compute Engine instance, the most effective method is to create the instance without a public (external) IP address. Without a public IP, the instance has no routable address from the Internet, effectively blocking all inbound public traffic regardless of firewall settings.

Question 143

Single Answer

Topic 1

Your team maintains the infrastructure for your organization. The current infrastructure requires changes. You need to share your proposed changes with the rest of the team. You want to follow Google's recommended best practices. What should you do?
  • A
    Use Deployment Manager templates to describe the proposed changes and store them in a Cloud Storage bucket.
  • B
    Use Deployment Manager templates to describe the proposed changes and store them in Cloud Source Repositories.
    Correct
  • C
    Apply the changes in a development environment, run gcloud compute instances list, and then save the output in a shared Storage bucket.
  • D
    Apply the changes in a development environment, run gcloud compute instances list, and then save the output in Cloud Source Repositories.
Explanation
Deployment Manager templates are Infrastructure as Code (IaC), which require version control for collaboration, review, and rollback capabilities. Google's best practices recommend storing IaC in a source code repository like Cloud Source Repositories rather than object storage like Cloud Storage.

Question 144

Single Answer

Topic 1

You have a Compute Engine instance hosting an application used between 9 AM and 6 PM on weekdays. You want to back up this instance daily for disaster recovery purposes. You want to keep the backups for 30 days. You want the Google-recommended solution with the least management overhead and the least number of services. What should you do?
  • A
    1. Update your instances' metadata to add the following value: snapshot—schedule: 0 1 * * * 2. Update your instances' metadata to add the following value: snapshot—retention: 30
  • B
    1. In the Cloud Console, go to the Compute Engine Disks page and select your instance's disk. 2. In the Snapshot Schedule section, select Create Schedule and configure the following parameters: - Schedule frequency: Daily - Start time: 1:00 AM — 2:00 AM - Autodelete snapshots after: 30 days
    Correct
  • C
    1. Create a Cloud Function that creates a snapshot of your instance's disk. 2. Create a Cloud Function that deletes snapshots that are older than 30 days. 3. Use Cloud Scheduler to trigger both Cloud Functions daily at 1:00 AM.
  • D
    1. Create a bash script in the instance that copies the content of the disk to Cloud Storage. 2. Create a bash script in the instance that deletes data older than 30 days in the backup Cloud Storage bucket. 3. Configure the instance's crontab to execute these scripts daily at 1:00 AM.
Explanation
Option B is correct because Google Cloud provides native scheduled snapshots for persistent disks, which automates creation and retention without requiring custom code or additional services.

This approach minimizes management overhead and uses the fewest services compared to building custom solutions with Cloud Functions (Option C) or instance-level scripts (Option D).

Option A is incorrect because snapshot schedules are not configured via instance metadata.

Question 145

Single Answer

Topic 1

Your existing application running in Google Kubernetes Engine (GKE) consists of multiple pods running on four GKE n1`"standard`"2 nodes. You need to deploy additional pods requiring n2`"highmem`"16 nodes without any downtime. What should you do?
  • A
    Use gcloud container clusters upgrade. Deploy the new services.
  • B
    Create a new Node Pool and specify machine type n2—highmem—16. Deploy the new pods.
    Correct
  • C
    Create a new cluster with n2—highmem—16 nodes. Redeploy the pods and delete the old cluster.
  • D
    Create a new cluster with both n1—standard—2 and n2—highmem—16 nodes. Redeploy the pods and delete the old cluster.
Explanation
In GKE, a single cluster can contain multiple Node Pools with different machine types.
Creating a new Node Pool allows you to add n2-highmem-16 nodes alongside existing n1-standard-2 nodes without disrupting current workloads.
This enables zero-downtime deployment of new pods requiring specific resources while maintaining availability.
